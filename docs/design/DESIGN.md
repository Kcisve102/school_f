# Design Contract — Knowverd

> **One-time override run.** Generated by `/ui-pipeline` in *new-project* mode at the
> user's explicit request, to exercise the generation phase. Normal runs use the
> redesign path and preserve the extracted thesis. Future sessions: read this file
> and follow the redesign rule.

---

## Thesis

A technical instrument, not a brochure. Monospace everywhere, zero ornament, and a
scale gap wide enough that the page has exactly one thing to look at per screen.
Restraint amplified until it reads as intent rather than absence.

**Source:** extracted from codebase, then amplified ("keep mono, push harder")

**Reference:** structural lessons from lenis.dev — drama comes from scale and
emptiness, not from layout tricks or color.

## Locks — decided once, at page level

| Lock | Value | Allowed roles |
|---|---|---|
| Accent | `#ffffff` | links, primary CTA fill, focus ring — never decoration |
| Radius system | `0` everywhere | no exceptions; `rounded-full` only for the avatar/pill |
| Theme | dark, fixed | no light mode; `color-scheme: dark` |

---

## Dials

| Dial | Value | Note |
|---|---|---|
| `DESIGN_VARIANCE` | asymmetric | deliberate grid breaks; sections must not share one rhythm |
| `MOTION_INTENSITY` | sharp / snappy | fast, linear-ish easing. No spring, no float, no drift |
| `VISUAL_DENSITY` | varied | alternating dense and near-empty. Uniform density is the failure |

## Tokens

Inherited from `src/index.css`. Unchanged by this override — the thesis is amplified
through **scale, rhythm, and structure**, not new color.

| Token | Value | Role |
|---|---|---|
| bg-primary | `#16171b` | page |
| surface | `#1c1d22` | cards |
| surface-secondary | `#232429` | insets, inputs |
| text-primary | `#ffffff` | headings, body |
| text-secondary | `rgba(255,255,255,0.7)` | supporting copy |
| text-muted | `rgba(255,255,255,0.5)` | meta — raised from 0.35, which failed AA |
| border | `rgba(255,255,255,0.1)` | hairlines |
| accent | `#ffffff` | interactive only |

**Type**

| | Family | Size | Weight | Tracking |
|---|---|---|---|---|
| display | JetBrains Mono | `clamp(2.5rem, 11vw, 9rem)` | 500 | `-0.04em` |
| section | JetBrains Mono | `clamp(1.75rem, 4.5vw, 3.5rem)` | 500 | `-0.03em` |
| eyebrow | JetBrains Mono | `0.6875rem` | 400 | `0.3em` uppercase |
| body | Manrope | `1rem`–`1.125rem` | 400 | normal |
| meta | JetBrains Mono | `0.75rem` | 400 | `0.12em` |

**The scale gap is the whole point.** Display to body is roughly 8:1 at desktop.
Anything in between weakens it — no `text-2xl` filler tier.

**Spacing:** `0 / 4 / 8 / 16 / 24 / 48 / 96 / 160` — jumps, not a smooth ramp.

**Motion budget:** 150–250ms, `cubic-bezier(0.2, 0, 0, 1)`. Opacity and transform
only. No scale-up on hover; use border and background instead.

---

## Motion architecture

- **Scroll-driven?** No. Reveals stay on IntersectionObserver — already implemented
  in `useScrollReveal`, already correct, and adding Lenis would fight the sharp feel.
- **Signature moment:** the hero headline. Oversized mono, set to a hard left edge,
  wrapping where the viewport dictates rather than where a designer would choose.
  Everything else on the page is quiet so this one thing carries.
- **Everything else:** restrained. Fast fades, no stagger longer than 240ms total.

---

## Lifted bans

| Ban | Reason |
|---|---|
| Section-numbering eyebrows (`01`/`02`) | Retained deliberately: this thesis is instrument-like, and numbered sections read as index/spec rather than decoration. Kept **monospace, muted, small** — never as a display element. |

All other bans hold. Specifically still banned: three-equal-card rows, mesh
gradients, scroll cues, decorative status dots, hand-rolled decorative SVG.
